Shrouded Citadel got a little rework lookwise.

The "Shrouded - Find A Cure" message is now an action message instead of a bar which will always refill.

There is now an npc which has a lot to tell about the Ithren. There is some introduction where you can tell him how less you care, or maybe how much you care. Anyways, after this introduction he is willing to give you information about all of them, which is rare in Void Tales. Normally you have the set up the lore yourself IF you are interested.
However, should you learn these informations and you know this little guy a little better... it is time to ask him why he is a skeleton. He does not know that and the event afterwards is a little shocking. Not only for him.
