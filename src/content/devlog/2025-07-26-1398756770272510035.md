The quest dialogue for the Bladeguess quest has been updated and now follows the new format

A bug was fixed where the adventurer kept receiving the same letter repeatedly

The "Don't Pet the Raccoon" sign is now also protected

The tree at the Soul Station now gives passing adventurers a Withered Acorn. Holding one increases the gold reward when opening a Boss Chest

A bug was fixed where the quest description for the quest Ellumscape was not displaying correctly

Fixed a typo that said the bomb could be used with Shift, when it actually works with Swing / Left Click

Fixed a bug where the Gemadillo only gave 1 Glimmer instead of 7, despite being intended to offer 7 every 8 hours

Fixed a bug where Whispers were not properly limited to a maximum of 10

The reward for the "Dreamnest" quest has been reworked – it was still giving the old Feral & Aegis Shards instead of the new Glimmer

Two lecterns containing bits of lore are now protected, preventing the books from being taken

Fixed a bug where the Ellum Voucher could not be redeemed for an Ellum

Fixed a bug where a new Ellum would be born if the player touched an existing Ellum while holding a Voucher

Players can no longer get hungry in the Grove Of Deities

Glimmer can now be stacked using the Mystic Box

The Skyloop game in the Grove Of Deities can now be replayed much more quickly
