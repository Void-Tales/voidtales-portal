**Q: What version is the server?**  
A: Void Tales runs on Minecraft Java Edition version `26.2`.

**Q: Where do I get the modpack?**  
A: The modpack can be downloaded from our [Modpack Page](https://modrinth.com/modpack/void-tales).
The current version is `2.1.1` for Minecraft 26.2.

**Q: I still have the old pack. Do I have to update?**  
A: No. Older Void Tales instances still connect to the server. The 26.2 pack is optional but
highly recommended - import it as a new instance so the old one stays as a fallback.

**Q: Do I still need the server's resource pack?**  
A: Yes. The modpack carries the visual packs, the server sends its own pack on join, and both
are needed for the full look. Accept it when prompted.

**Q: What is the difference between Full and Lite Visuals?**  
A: Lite Visuals loads faster and keeps the Void Tales look including custom gear models. Full
Visuals adds the redrawn blocks, armour, and weapons. Switch any time from the title screen.

**Q: Where is the world map?**  
A: [dynmap.voidtales.win](https://dynmap.voidtales.win) - it is a 3D map now, same link as before.

**Q: How do I join the Discord?**  
A: [Click here to join](https://discord.gg/QEMQsFect6).
